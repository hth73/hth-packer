## Description

HashiCorp Packer is an open-source tool that automates the creation of machine images. It enables developers and administrators to create identical images for various platforms (such as AWS, Azure, GCP, VMware, and Docker) from a single configuration file.

Here you can find a few packer examples with Windows Server and Ubuntu Server.
